How to generate certificates from Google Sheets

You have a sheet of attendees or students and need one certificate each. Here is the free way to do it with a Google Docs template, and how to automate it.

What you need

  • A Google Sheets spreadsheet with one row per person and a header row, for example Name, Course, Date, Instructor, Certificate ID.
  • A Google Doc that will be your certificate template.

Tip: format the Date column the way you want it printed. In Google Sheets, select the cells and click Format → Number, then pick a date format (Google: Format numbers in a spreadsheet).

Method 1: by hand with a Google Docs template (free)

  1. Make the page landscape. In your template Doc, click File → Page setup, select Pages, set Orientation to Landscape and click OK. Page orientation isn't available in pageless documents, so the Doc has to be in pages format (Google: Change page settings on Google Docs).
  2. Write the certificate with placeholders. Type the fixed wording and put a tag wherever a person's details go, such as {{Name}}, {{Course}} and {{Date}}. Style the tags the way the final text should look (font, size, color). Google's developer guide recommends tags that are “unlikely to occur normally”, and double braces are a common choice (Google for Developers: Merge text into a document).
  3. Copy the template for one person. Click File → Make a copy, type a name such as “Certificate - Avery Example”, choose a folder and click OK (Google: Create, view, or download a file).
  4. Fill in the copy. In the copy, click Edit → Find and replace. Put {{Name}} next to “Find”, paste the person's name from the sheet next to “Replace with”, tick Match case and click Replace all. Repeat for each tag (Google: Search and use find and replace).
  5. Save a PDF. Click File → Download and choose PDF. For a large Doc in Chrome, Google suggests File → Print with Destination set to “Save as PDF” (same Google page).
  6. Keep track. Paste the new Doc's link into a “Certificate link” column in your sheet so you know who is done.

This works well for a handful of people. The work grows with the list: 40 people with 4 tags each is 40 copies and 160 Replace all actions, plus 40 downloads, and every one is a chance to paste the wrong name.

Variable chips (work and school accounts)

On eligible work or school accounts, Google Docs has variable chips: go to Insert → Smart chips → Variables, and when you change a variable's value it updates everywhere it's used in that Doc (Google: Insert and use variable chips). That replaces the Find and replace step, but you still make one copy per person and type each value yourself. Google's help page says variable chips are only available for eligible work or school accounts.

Method 2: a script (for developers)

Google documents the same template idea for code: copy the template with the Drive API's files.copy, then replace the tags with the Docs API's ReplaceAllTextRequest (Merge text into a document). Looping that over your sheet's rows gives you one certificate per row, but you write, authorize and maintain the script yourself.

Method 3: let RowStamp do the copying

RowStamp is a spreadsheet add-on that automates Method 1. It creates a ready-made landscape certificate template as a Google Doc you can edit, matches tags like {{Name}} to your column headers automatically, and then makes one Doc per row (all rows, a range like 2-20, or the rows you selected). It writes a “RowStamp doc” link and, if you want, a “RowStamp PDF” download link in new columns next to your data. Your existing cells are never changed, and rows that already have a certificate are skipped the next time you run it.

It asks for only two permissions: the spreadsheet you open it in, and the Google Drive files it creates or that you choose. The free plan includes every feature, up to 10 documents per day; Pro removes the daily limit.

Availability: RowStamp will be available as a Google Sheets add-on after Google Workspace Marketplace review. Once installed, open it from the add-ons side panel in Google Sheets.

Tips for better certificates

  • Give every row a unique Certificate ID (CERT-0001, CERT-0002…) so a certificate can be checked against your sheet later.
  • Check name spelling and capitalization in the sheet first. Fixing one cell is easier than fixing a finished certificate.
  • Keep the tag text exactly the same as the column header, including spaces, so it's obvious which column fills which tag.
