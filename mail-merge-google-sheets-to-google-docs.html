Mail merge from Google Sheets to Google Docs, without sending email

“Mail merge” in Google usually means Gmail. If what you need is a document per row (a letter, a confirmation, a certificate) rather than an email, this is how to do it.

Gmail mail merge vs a document per row

Gmail mail mergeDocs merge (one Doc per row)
ResultA personalized email to each recipientA separate Google Doc (and PDF) for each row
DataRecipients in the first tab of a spreadsheet; column headers become merge tags like @firstnameAny tab; column headers fill tags like {{Name}}
Who can use itEligible Google Workspace plans (listed below)Anyone with Google Docs (by hand); add-ons and scripts vary
LimitsUp to 1,500 mail merge recipients per dayYour time, or the tool's limits

According to Google's Gmail help, mail merge sends each recipient a unique copy of an email with the merge tags filled in, contact data must be in the first tab of the spreadsheet, and you can send to a maximum of 1,500 recipients per day. It needs one of these plans: Workspace Individual, Business Standard, Business Plus, Enterprise Standard, Enterprise Plus, Education Standard or Education Plus (Google: Send personalized emails with mail merge). It does not produce documents. If you want files to print, sign, archive or attach, use one of the methods below.

Method 1: merge by hand with a Docs template (free)

  1. Prepare the sheet. One row per document, with a header row: Name, Address, Start Date, and so on. Format dates and money in the sheet the way you want them printed, with Format → Number (Google: Format numbers in a spreadsheet).
  2. Write the template. In Google Docs, write the letter once and put a tag where each value goes: “Dear {{Name}}, your start date is {{Start Date}}.” Google's developer guide calls this a template with fixed text and placeholders, and suggests tags “unlikely to occur normally” (Google for Developers: Merge text into a document).
  3. Copy it per row. File → Make a copy, give it a name that includes the row's key value, choose a folder and click OK (Google: Create, view, or download a file).
  4. Fill the copy. Edit → Find and replace: find each tag, replace it with that row's value, tick Match case and click Replace all (Google: Search and use find and replace).
  5. Export if needed. File → Download → PDF (same Google page).

Fine for five letters, tedious for fifty: every row means a copy, one replacement per tag, and a download.

On eligible work or school accounts, Docs variable chips (Insert → Smart chips → Variables) update a value everywhere it appears in a Doc once you set it (Google: Insert and use variable chips). They save the find-and-replace step, but the values still don't come from your sheet automatically.

Method 2: a script

For developers, Google documents the merge as two API calls per document: copy the template with the Drive API's files.copy, then fill the tags with a ReplaceAllTextRequest in the Docs API's batchUpdate (Merge text into a document). Google also publishes an Apps Script sample that fills a Gmail draft template with Sheets data and sends the emails from your Gmail account; that is the email version, not the document version (Create a mail merge with Gmail & Google Sheets).

Method 3: RowStamp (no email, no code)

RowStamp is a spreadsheet add-on built for exactly this: a Docs merge with no email step. Use one of your own Docs as the template (open it and choose it from the RowStamp panel in Docs) or start from the built-in certificate or invoice template. Tags like {{Name}} are matched to your column headers automatically, and you can change any match under Check fields. Pick all rows, a range like 2-20, or the rows you selected, and click Fill documents. Each row becomes its own Doc, with a “RowStamp doc” link and an optional “RowStamp PDF” download link added next to your data. RowStamp doesn't send emails.

It asks for only two permissions: the spreadsheet you open it in, and the Google Drive files it creates or that you choose. Free for 10 documents a day; Pro removes the daily limit.

Availability: RowStamp will be available as a Google Sheets add-on after Google Workspace Marketplace review. Once installed, open it from the add-ons side panel in Google Sheets.

Common uses for a Docs merge

  • Offer letters, welcome letters and confirmations
  • Certificates for courses, training and awards
  • Invoices and receipts, one per order
