How to create invoices from Google Sheets rows

Your orders or jobs already live in a spreadsheet. Here is how to turn each row into its own invoice as a Google Doc and PDF, by hand for free, and how to automate it.

Step 1: set up the sheet (one row = one invoice)

Use a header row and one row per invoice. A layout that works:

Invoice NumberDateDue DateClient NameDescriptionQuantityRateAmount
1001Oct 6, 2026Nov 5, 2026Example Catering Co.Event staffing10$50.00$500.00
  • Let the sheet do the math: in the Amount column use a formula such as =F2*G2 (Quantity times Rate) and fill it down.
  • Format money and dates the way they should be printed: select the cells, click Format → Number and choose a currency or date format (Google: Format numbers in a spreadsheet). When you copy a value into a document, use what the cell shows.
  • Add a Status or Invoice link column so you can see which rows already have an invoice.

Step 2: build the invoice template in Google Docs

Create a Doc with your business name, contact details and payment terms. Wherever a value from the sheet goes, type a tag in double braces that matches the column header: {{Invoice Number}}, {{Date}}, {{Client Name}}, {{Amount}} and so on. A small table for the line works well:

DescriptionQtyRateAmount
{{Description}}{{Quantity}}{{Rate}}{{Amount}}

Google's developer guide describes this exact pattern (a template with fixed text plus tags, copied and then filled), and suggests tags that are “unlikely to occur normally” so nothing else gets replaced by mistake (Google for Developers: Merge text into a document).

Step 3: make each invoice by hand (free)

  1. Open the template and click File → Make a copy. Name it, for example “Invoice 1001 - Example Catering Co.”, choose a folder and click OK (Google: Create, view, or download a file).
  2. In the copy, click Edit → Find and replace. Find {{Client Name}}, replace it with the client's name from the row, tick Match case and click Replace all. Repeat for each tag (Google: Search and use find and replace).
  3. Click File → Download and choose PDF to get a file you can send (same Google page).
  4. Paste the invoice link into the row and mark it done.

That's fine for a few invoices a month. With 30 invoices and 8 tags it's 30 copies and 240 replacements, and a mistyped amount on an invoice is worse than on most documents.

On eligible work or school accounts, Google Docs variable chips (Insert → Smart chips → Variables) let you set a value once and have it update everywhere it's used in the Doc (Google: Insert and use variable chips). You still copy the template and type each value per invoice.

Invoices with several line items

Placeholder filling works one value per tag. Google's developer guide points out that a list of items whose length isn't known in advance (such as invoice lines) can't be done with plain text replacement and needs extra table logic in code (same guide, “Handle dynamic lists and tables”). Without code, the simple options are:

  • Fixed line columns: Item 1, Amount 1, Item 2, Amount 2… with matching tags in the template, left empty when unused.
  • One summary line per invoice, such as “Event staffing, Oct 1-5 (see attached timesheet)”.

Automate it with RowStamp

RowStamp is a spreadsheet add-on that does Step 3 for you. It includes a built-in invoice template that it creates as a Google Doc you can edit and brand, matches tags to your column headers automatically (capitals, spaces, dashes and underscores don't matter), and makes one invoice Doc per row for all rows, a range like 2-20, or the rows you selected. It writes a “RowStamp doc” link and an optional “RowStamp PDF” download link in new columns next to your data, never changes your existing cells, and skips rows that already have an invoice, so you can add new orders and run it again.

RowStamp doesn't send emails; you send or share the PDF yourself. It asks for only two permissions: the spreadsheet you open it in, and the Google Drive files it creates or that you choose. Free for 10 documents a day; Pro removes the daily limit.

Availability: RowStamp will be available as a Google Sheets add-on after Google Workspace Marketplace review. Once installed, open it from the add-ons side panel in Google Sheets.

Before you send an invoice

  • Use a unique, increasing invoice number in every row and never reuse one.
  • Check what your country or state requires on an invoice (tax IDs, tax lines, addresses). This guide covers the mechanics, not tax or legal advice.
