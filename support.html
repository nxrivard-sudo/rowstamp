Getting started

  1. Put one record per row on a tab, with column names in row 1 (for example Name, Course, Date).
  2. Open RowStamp from the add-ons side panel in Google Sheets.
  3. Click New certificate or New invoice. RowStamp creates an editable template in a "RowStamp" folder in your Drive. Click Open template to change the wording, add your logo, or move fields.
  4. Click Check fields to confirm which column fills each placeholder.
  5. Enter the rows (or select them and click Use selected rows), then click Fill documents.

Want to try it first? Under Try it with sample data, RowStamp adds a tab with three made-up rows that match the built-in template.

Using your own Google Doc as a template

  1. Open the Doc in Google Docs and type column names in double braces where values should go, like {{Name}} or {{Invoice Number}}.
  2. Open RowStamp from the Docs side panel and click Allow access to this document. This gives RowStamp access to that one file only.
  3. Click Use as template. It now appears in the template list in Google Sheets.

FAQ

Does it change my data? No. It adds "RowStamp doc" (and optionally "RowStamp PDF") columns to the right of your data. The template is copied, never edited.

How are placeholders matched to columns? By name, ignoring capitals, spaces, dashes and underscores: {{Client Name}} matches a "client_name" column. If a placeholder has no clear match, RowStamp asks you to pick a column or leave it blank.

Do placeholders keep my formatting? Yes. The filled value takes the placeholder's font and style. Values are filled as they appear in the sheet, so dates and currency look the same as in your cells.

How do I get a PDF? Tick Add a PDF download link column. Clicking a link downloads that document as a PDF directly from Google.

Why did it stop partway? Google limits each add-on click to about 30 seconds, usually enough for about 10 documents, depending on the template. Click Fill documents again; rows that already have a document are skipped. On the free plan, the limit is 10 documents per day.

Can it see my other files? No. RowStamp can only open files it created or that you chose with Allow access to this document. See Privacy.

Does it send emails? No. RowStamp only creates documents and links.
